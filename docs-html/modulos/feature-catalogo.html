Catalogo Canonico de Features

Inventario operativo de features por familia, estrategia, fuente, fase y bundle.

Inicio / Modulos / Modulo Feature Store / Feature Engine / Catalogo Canonico de Features

Proposito

Esta pagina aterriza el catalogo maestro introducido en app/features/catalog.py. Su funcion no es enumerar formulas sueltas, sino fijar un lenguaje comun para saber que features existen, para que familias de estrategia sirven, que fuente requieren y en que fase de implementacion se encuentran.

Lectura operativa del catalogo

  • El catalogo ya es la capa canonica para describir el universo de features, aunque no todas esten implementadas todavia.
  • Implemented significa que el wiring actual esta defendible y probado.
  • Planned significa que la feature forma parte del baseline objetivo, pero su wiring real o su bundle aun no estan cerrados.
  • Future significa que requiere nuevas fuentes o una ampliacion mayor de plataforma.

Discovery

Desde CLI

Usa python scripts/feature_catalog.py --family trend --format names para extraer las entradas de una familia concreta. Tambien se puede filtrar por bundle, estado, fase o estrategia.

Desde API

Los endpoints /catalog/features, /catalog/families, /catalog/strategy-families, /catalog/source-scopes y /catalog/bundles devuelven la misma taxonomia para UI, tooling o integracion con research.

Uso recomendado

Elegir primero una familia de estrategia, despues un bundle y por ultimo verificar que las features requeridas estan marcadas como implemented para el target deseado.
