Lectura operativa verificada

El catalogo visible ya no se limita al engine principal. Hoy el despliegue local muestra tres servicios Compose con papeles distintos: app como runtime base, webUI como interfaz operativa interna y control-plane-worker como ejecutor asincrono de comandos del plano de control.

Interacciones operativas verificadas

  • El operador solo entra por webUI; no hay interfaz HTTP directa hacia app.
  • webUI y el worker comparten la DB SQLite del control plane para cola y auditoria.
  • El engine y el control plane se coordinan mediante filesystem compartido y JSONL append-only, no mediante consultas al hot path.
  • La recuperacion lanzada desde la UI es asincrona y queda visible en Audit.
