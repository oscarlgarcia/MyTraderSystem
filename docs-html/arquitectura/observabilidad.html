Lectura de observabilidad verificada

La observabilidad visible en el repo se apoya en tres superficies principales: logs JSON estructurados, metricas y summaries de ingestion y alertas operativas con severidad y accion recomendada. Ademas, los artefactos de readiness, canary, soak y release gates actuan como evidencia viva para promotion y diagnostico.

Logs y trazabilidad

  • Los logs son JSON y redaccion campos sensibles por clave o patron de valor.
  • trace_id se propaga via ContextVar y se anade a cada log cuando esta presente.
  • El logger puede emitir a stdout y a fichero rotado, registrando ademas log_file_metrics sobre tamano y backups.
  • La forma canonica de alerta es message = operational alert con alert_type, alert_severity, observed, threshold y recommended_action.
