Proposito

Resumir las decisiones arquitectonicas aprobadas que ya condicionan contratos, datasets y criterios de promotion. Esta pagina no reemplaza las ADRs individuales: las indexa y explica por que importan desde la perspectiva de arquitectura.

ADRs aprobadas con impacto arquitectonico

ADREstadoContextoDecision aprobadaConsecuencia arquitectonica
ADR-0001AprobadaFaltaba cerrar el alcance historico del modulo de ingestion para soportar roadmap tick/trade sin ambiguedad contractual.El soporte historico aprobado queda fijado en kline y trade.El contrato de ingestion y el promotion path deben garantizar parity raw -> replay -> normalized para ambos feeds.

Contexto y consecuencias transversales

Arquitectura debe tratarlas como hechos aprobados mientras no exista una ADR posterior que las sustituya.
